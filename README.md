# Early Programming Archive

Programlama öğrenme döneminden kalan Android, Java ve Python çalışmalarının
düzenlenmiş tarihsel arşivi.

## Koleksiyon

### Android

- Sayı tahmin oyunu
- Kitap uygulaması denemesi
- Şifre oluşturma/belirleme uygulamaları
- İlk Android ve Jetpack Compose alıştırmaları

### Java / NetBeans

- Caesar şifreleme arayüzü
- Haber türü sınıflandırma denemeleri
- Nesne yönelimli programlama ödevleri

### Python

- Döviz hesaplama
- Hava durumu hatırlatıcısı
- Hesap makinesi ve matris işlemleri
- Saat, veri analizi ve Selenium denemeleri

## Amaç

Bu repo güncel üretim kalitesini temsil etmekten çok öğrenme yolculuğunu ve
erken dönem problem çözme çalışmalarını korur. Derleme çıktıları, IDE önbelleği
ve yerel ortam dosyaları arşive dahil edilmemiştir.
