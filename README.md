# Early Programming Archive

Historical Android, Java and Python learning projects preserved with their original
project boundaries. These exercises document an early learning period and are not
presented as maintained production applications.

## Collection and environments

- `android/AndroidStudioProjects/`: seven independent Gradle/Android projects,
  including number guessing, book-app and password-generator exercises.
- `java/`: independent Java/NetBeans/Swing and object-oriented programming work.
- `python/`: small currency/weather/calculator/matrix/clock/data/Selenium exercises.

Inspect the selected project's build files and source first. Android projects need
their own compatible JDK/Gradle/Android SDK combinations; open a single project in
Android Studio rather than building the entire archive from the root. Gradle
wrapper JARs are legitimate build inputs and are intentionally retained.
Java projects may require the original IDE/build layout. Python scripts have
different GUI, browser, network and local-file dependencies; there is no common
root requirements file or supported one-command execution path.

## Validation and limitations

The audit reviewed structure and parsed Python source. Historical Android/Java
build environments were not reconstructed, and GUI/browser/network scripts were
not run. Seven Android `ExampleUnitTest` files are template checks, not meaningful
evidence of application behavior. No shared passing badge or build success is claimed.

Preserve archives and source history. Related content in `Projelerim` may warrant
a future ownership/duplication review, but no automatic consolidation or deletion
is authorized by this README. Run historical network/browser code only against
targets you control, and keep personal data, credentials and generated outputs
outside commits.
